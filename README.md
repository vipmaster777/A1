# Zodiac HR Fit

MVP веб-приложение на **Next.js (App Router) + Tailwind CSS** с JSON-хранилищем профилей вакансий.

## Быстрый старт

```bash
npm install
```

Создайте `.env.local`:

```env
OPENAI_API_KEY="your_openai_key"
```

Запуск:

```bash
npm run dev
```

Seed-профили создаются автоматически при первом обращении к `/api/roles`.
